Keep the attendance homepage notice separate from admin-authored pinned posts. Admin posts belong only in the Reyi feed at /chat, not the homepage or the separate night-only /reyi space.

**Why:** The user explicitly chose “Reyi feed only” when asked where admin-written pinned messages should appear. The homepage outage notice was a separate, specifically placed request.

**How to apply:** Preserve that separation when extending announcement management. Admin publishing must not silently start distributing messages to the homepage or night-only space.
